# PlasticMarket — Sitio web

Fabricación de productos industriales de plástico y caucho termoplástico en Chile.

Sitio 100% estático (HTML + CSS + JS plano, sin frameworks ni build). Listo para GitHub Pages, Vercel, Netlify o cualquier hosting estático.

## Estructura
- `*.html` — Páginas (inicio, productos, servicios, contacto y una página por producto)
- `css/style.css`, `js/main.js` — Estilos y comportamiento
- `img/` — Imágenes (`img/t/` contiene miniaturas livianas para el catálogo), logos y video de matricería
- `CNAME`, `robots.txt`, `sitemap.xml` — Dominio y SEO

El formulario de contacto envía a `ventas@plastic-market.com` mediante FormSubmit (la primera vez hay que confirmar el correo de activación).
