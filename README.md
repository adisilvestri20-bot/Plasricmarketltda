# PlasticMarket — Sitio web

Fabricación de productos industriales de plástico y caucho termoplástico en Chile.

Sitio 100% estático (HTML + CSS + JS plano, sin frameworks ni build). Listo para GitHub Pages.

## Estructura
- `*.html` — Páginas del sitio (inicio, servicios, productos, fichas de producto, contacto, privacidad)
- `css/style.css` — Estilos
- `js/main.js` — Scripts
- `img/` — Imágenes y videos
- `CNAME` — Dominio plastic-market.com
- `sitemap.xml`, `robots.txt` — SEO
